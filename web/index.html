Refresh from your phone

    
Offers already update by themselves every morning at 6am. To refresh whenever you like,
      connect a GitHub key that can only start this app's refresh. It's saved on this phone only.

    
    
    

      How do I get a key?
      
    
        
  1. On github.com, open Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
    2. 
        
  2. Name it Lugma refresh, set Expiration to 1 year.
    3. 
        
  3. Repository access → Only select repositories → pick your Lugma repo.
    4. 
        
  4. Permissions → Repository permissions → Actions → Read and write. Nothing else.
    5. 
        
  5. Generate, copy the key, paste it above.
    6.
